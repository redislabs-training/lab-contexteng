# LLM Connection Test

Simple page to test LiteLLM proxy connectivity.

## Quick Start

```bash
export DOMAIN="nip.io"
export HOSTNAME="127.0.0.1"
export GENAI_WKSHP_OPENAI_API_KEY="your-openai-key"
./start.sh
```

Then open http://localhost in your browser and click "Test LLM Connection".

## Stop

```bash
./stop.sh
```
